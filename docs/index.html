⚡ Fnote

Ultra-fast note-taking for Windows. Python-powered, tag-based, with screenshot capture.

Download View on GitHub

Features

⚡ Instant Notes

Press Ctrl+Alt+N, type your note, hit Enter. It's saved.

🏷️ Tags & Aliases

Use /work in your notes. Aliases like /w work too.

🤖 Auto-tagging

Regex rules tag notes automatically based on content.

📷 Screenshots

Capture screen areas and attach them to notes. Paste from clipboard.

🔍 Viewer

Browse, search, filter by tag/date, edit, and delete notes.

💻 Local & Portable

SQLite database, no cloud. Runs from a USB stick.

Installation

Download Fnote.exe from the Releases page and run it. No installation needed.

On first launch, it creates config.ini and a data/ folder next to the executable.

Configuration

Edit config.ini to customize tags, colors, shortcuts, and auto-tagging rules:

[tags]
work = #FF5733
personal = #33A8FF
urgent = #FF0000
idea = #FFD700

[tag_aliases]
w = work
i = idea

[auto_tags]
urgent = \burgent\b|\bASAP\b|\bdeadline\b
work = \bclient\b|\bmeeting\b|\bproject\b

Build from Source

git clone https://github.com/luca-deste/fnote.git
cd fnote
pip install -r requirements.txt
python fnote.py

# Build .exe
python -m PyInstaller fnote.spec
